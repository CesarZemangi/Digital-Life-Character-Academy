Privacy Policy

Privacy-first learning platform

Digital Life Academy is committed to protecting learner privacy and avoiding unnecessary personal data collection. We use data only where it supports platform safety, learning progress, and product improvement.

What data may be collected

  • Basic account information such as email address and Google authentication metadata.
  • Learning progress such as lesson completion, quiz results, points, and certificates.
  • Anonymous usage information such as device type, feature usage, and lesson engagement.
  • Technical session data needed to ensure secure sign-in, account access, and product reliability.

How we use data

We use data to provide a personalised learning dashboard, track progress, measure learning outcomes, improve usability, and maintain platform safety and security. We do not sell personal data to third parties.

Data minimisation

We limit collection to information that is necessary for the service. Sensitive personal information should only be collected when there is a clear and legitimate reason, and it should be strongly protected with secure access controls.

Security

We aim to store learner data securely using modern authentication, database protection, and access controls. In the production version, all important user and learning records should be stored in Supabase. We recommend using strong passwords and keeping login details private, and administrators should change any default password immediately after first login.

Children and young learners

If this platform is used by minors, extra care should be taken to avoid collecting unnecessary personal details and to provide clear parental, teacher, or guardian oversight where relevant.

Changes

We may update this policy as the platform evolves. Continued use of the platform after changes are published means the user accepts the updated policy.
